# AU GPU Listing Scan

Query AU marketplace listings for GPU deals and keep a ledger of deals already reported.

## Tools

- `listing_search` — Search AU marketplace listings through the local searxng backend and return ranked title, url and snippet hits. (http)
- `listing_ledger` — Read or write the plugin own JSON ledger of GPU deals already reported, so a weekly brief does not re-pitch them. (file)

## Install

```bash
hermes plugins validate /path/to/au-gpu-listing-scan
ln -s /path/to/au-gpu-listing-scan ~/.hermes/plugins/au-gpu-listing-scan
```
